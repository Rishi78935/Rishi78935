### Aahaar Scanner

A working prototype combining spectral sensing, embedded hardware, data collection, and on-device inference for fruit quality analysis.

**Current work includes:**
- ESP32-S3 embedded platform
- AS7341 spectral sensor
- AS7265x used during an earlier prototype stage
- OLED and 2.8" TFT display integration
- Optical/illumination setup
- Dataset collection and processing
- Schematic and PCB design
- Embedded model inference

### Maglev: Electromagnetic Levitation & PID Control

An experimental electromagnetic levitation system using:
- Electromagnet coil
- Hall sensor feedback
- MCU-based control
- PWM coil control
- PID feedback control

**Physical levitation has been achieved**, and the system is still under development.
